## Reporting a Vulnerability

ALBEDO is an offline CPU ray tracer with no network access, no external input parsing
beyond local scene files, and no attack surface in the traditional sense. That said, if
you find a memory-safety issue, a crash on malformed input, or anything else that looks
like a security concern:


Open a GitHub Issue with a minimal
reproduction, or
Reach out to me directly if you'd prefer not to disclose it publicly first.


I'll aim to acknowledge reports within a few days.
