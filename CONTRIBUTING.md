# Contributing

TLDR: this is a one-person operation, I havent earned the right to have collaborators yet.

ALBEDO is a solo learning project. I'm implementing it . Because of that,I'm not
accepting pull requests, in part because the architecture is still shifting under my
feet, and the whole point isthat *I* write every line, bugs and all.

What I *do* want:

- **Issues.** Found a bug, a numerical footgun, or a BVH split heuristic that made you
  raise an eyebrow? Open an issue. I read every one.
- **Questions and discussion.** Curious about a design decision or something in the
  whitepaper? Ask.

What I don't want (yet):

- Pull requests. Not because I don't appreciate the thought — I just haven't earned the
  right to have collaborators clean up after me.

If ALBEDO ever grows up into a project that accepts contributions, this file gets a
rewrite, complete with actual guidelines instead of vibes. Until then: thanks for
stopping by, and go easy on the code, it's doing its best.
